 <h1 align="center">Kubernetes Deep Dive With Kind</h1>

## Overview
A hands-on repository for exploring Kubernetes in depth using Kind (Kubernetes in Docker), with practical labs and CKA exam preparation.

## Tech Stack
- Kubernetes
- Kind
- Docker
- kubectl
- YAML

## Architecture
Local Kubernetes clusters running through Kind, with Docker containers acting as Kubernetes nodes.

## What I'll Practice
- Kubernetes Core Concepts
- Pods, Deployments & Services
- ConfigMaps & Secrets
- Networking & Storage
- RBAC & Security
- Troubleshooting & Debugging
- CKA Exam Scenarios
